# Calculadora Financiera

Proyecto de aula de Ingeniería Económica. Calculadora web pensada para el celular: cada resultado muestra la fórmula de la hoja de clase que se usó, el procedimiento con los números y un gráfico.

**Abrir la app:** https://juanfernando23.github.io/calculadoraingeco/

## Qué hace

- **Interés compuesto:** valor futuro, valor presente, tasa o tiempo (fórmulas 2.1 a 2.4), con la conversión de la tasa a la unidad del tiempo (1.1 a 1.6, 3.1 y 3.2).
- **Gráfico animado** en tres vistas: diagrama de flujo de caja, barras y área.
- **Explícame:** recorre el resultado paso a paso, también en voz alta.
- **¿Y si…?:** mueve la tasa o el tiempo y mira cómo cambia el resultado (el efecto exponencial).
- **Historial** de los últimos cálculos y **app instalable** que funciona sin internet.

Conversión de tasas, tasas indexadas y anualidades están en construcción.

## Cómo usarla

- **Celular:** abre el enlace. Para instalarla, en Android toca "Instalar"; en iPhone, Compartir → Agregar a inicio.
- **Computador:** el mismo enlace, o `index.html` con doble clic (así funciona todo menos la instalación).

## Pruebas de cálculo

`pruebas.html` muestra cada caso con ✓ o ✗. En la terminal: `node pruebas.js`.
